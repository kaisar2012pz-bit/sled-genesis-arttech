# След — дневник ощущений

Прототип для Genesis Hackathon · ArtTech. «След» превращает день в интерактивную фотосцену и сохраняет запись вместе с исходными материалами в локальном архиве.

## Запуск

Самый простой запуск — откройте Sled.html в Edge или Chrome. Для запуска версии из исходников нужны Python 3 и современный браузер. Из папки с этим файлом выполните:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

На Windows вместо `python` можно использовать `py`. Откройте **http://127.0.0.1:8765/**. Адрес и порт определяют, какой локальный архив откроет браузер. Для прямого запуска используйте Sled.html, а не dist/index.html.

## Что проверить

1. В архиве откройте «Осенний парк и тёплое какао», «Ночь в офисе перед сдачей» и любой из трёх остальных дней. Послушайте музыку и откройте «Почему день выглядит так».
2. Нажмите «Новый день». Введите текст, приложите одну или несколько фотографий и выберите аудиофайл либо ссылку. Для ссылки добавьте описание звучания или выберите ритм. Для проверки можно взять изображения и WAV из `dist/media`.
3. Нажмите «Собрать воспоминание». Проверьте заголовок, переключение фотографий, песню и объяснение. Загруженный файл и прямая HTTPS-ссылка на аудио воспроизводятся в плеере. Ссылка на трек Spotify позволяет загрузить встроенный плеер. Любую сохранённую ссылку можно открыть в новой вкладке.
4. Перезагрузите вкладку, вернитесь в архив и снова откройте запись. Для прослушивания голосом нажмите «Озвучить запись». Темп и высота речи зависят от оформления, наличие русских голосов зависит от браузера и ОС.

В архиве пользовательские дни хранятся в отдельных записях IndexedDB с собственным названием, адресом и исходными файлами. Браузер заново рисует сцену из сохранённых настроек. Озвучка воспроизводится по запросу и не сохраняется аудиофайлом. Очистка сайта в браузере удаляет пользовательские дни. Ссылка на внешний трек требует интернета.

## Исходники и вклад

- `dist/engine.js` вычисляет заголовок, параметры текста, цветовой профиль фото и оценку энергии аудио.
- `dist/app.js` реализует запись, хранение файлов, маршруты папок, архив, просмотр и озвучку.
- `dist/index.html` и `dist/style.css` задают интерфейс и сцену.
- `make_demo_audio.py` синтезирует пять оригинальных демотреков средствами Python. Для этих дорожек предоставляется CC0.
- `capture.cjs` проверяет сценарии в браузере и сохраняет кадры для демонстрации. Для запуска нужны Playwright и Chromium или Edge. Сценарий подставляет локальные файлы вместо HTTP-запросов.
- `submission/` содержит материалы для сдачи.

## Инструменты и ресурсы

HTML, CSS, JavaScript, Canvas 2D, IndexedDB, Web Audio API и Speech Synthesis API. Без серверной базы. Для треков Spotify используется официальный встроенный плеер, который загружается по нажатию. Python 3 для локального запуска и синтеза демотреков, Playwright и Edge для проверки и съёмки, FFmpeg для монтажа, ReportLab для PDF. OpenAI Codex использовался при разработке и подготовке материалов. Генеративных моделей в самом дневнике нет.

Дни вымышлены. Фото — демонстрационные кадры Unsplash, точные источники указаны в `submission/REFERENCES.md`.



## Публикация

Точка входа сайта находится в `dist/index.html`. В этой папке находятся все файлы, требуемые хостингом. Зарегистрированные пользователи хостинга для посетителей сайта не нужны.

Для GitHub Pages предусмотрен workflow `.github/workflows/pages.yml`. В настройках репозитория выберите **Settings → Pages → Source → GitHub Actions** и запустите **Publish Sled to GitHub Pages**. После успешного запуска адрес сайта появится в настройках Pages и в результате workflow.

- [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- [Документация плеера Spotify](https://developer.spotify.com/documentation/embeds/tutorials/creating-an-embed)
